# Big Data Modelling and Management: 🍺 The Beer Project - Graph Database Analysis 🍺

This project explores the use of **graph databases** to analyze beer and brewery data, leveraging the power of **Neo4j** and the **Cypher** query language. It was developed as part of an academic assignment in the context of Big Data Modeling, focusing on graph-based data analysis and optimization.

The dataset, originally sourced from **Kaggle** and curated by **Evan Hallmark**, includes information on beers, breweries, user reviews, and associated metadata such as alcohol content, beer style, and review scores (e.g., smell, feel, taste).

We used **Neo4j**, a leading graph database, to explore, clean, model, and query this dataset with the aim of delivering insights to two fictional departments within a company: **Analytics** and **Market Analysis**.

## 🎯 Objectives

The goal was to simulate a real-world data management task in which we:

- Load and explore a graph database
- Adjust and optimize the schema
- Query the database to generate analytical reports
- Apply **Graph Data Science (GDS)** algorithms to uncover deeper relationships
- Ensure performance improvements and query efficiency

---

## ⚙️ Technologies Used

- **Neo4j 4.4.5**
- **Cypher**
- **Graph Data Science (GDS) Library**
- **APOC Library** for advanced procedures
- **Docker** for containerized Neo4j deployment
- **Python** with Neo4j connector (optional for extra exploration)
